OOP Student Management System

About the Project

The Student Management System is a console-based Java application developed using Object-Oriented Programming (OOP) concepts. It helps manage student records efficiently.

Features

- Add new student records
- View all student details
- Search students by ID
- Delete student records
- Prevent duplicate student IDs
- Validate student information
- Handle invalid inputs
- Simple menu-driven interface

Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- Exception Handling

OOP Concepts Implemented

- Encapsulation: Protects student data using private variables.
- Classes and Objects: Represents students as objects.
- Constructors: Initializes student information.
- Methods: Organizes operations into reusable blocks.

How to Run

1. Install the Java Development Kit (JDK).

2. Save the program as "Main.java".

3. Open a terminal in the project folder.

4. Compile the program:
   
   "javac Main.java"

5. Run the program:
   
   "java Main"

Menu Options

1. Add Student
2. View All Students
3. Search Student
4. Delete Student
5. Exit

Storage

Student records are stored in an ArrayList during program execution. Records are not permanently saved after the program closes.

Project Purpose

This project demonstrates practical Java programming and OOP fundamentals through a student record management application.
